# Application de recettes

Une petite application web pour ranger mes recettes, les chercher par ingrédient et générer une liste de courses.

## Fonctionnalités
1. Ajouter une recette (titre, ingrédients, étapes, photo)
2. Recherche par ingrédient
3. Liste de courses d'une semaine de menus

Les choix sont détaillés dans [[Choix techniques]]. Je m'en sers aussi pour apprendre [[Rust - Les bases]].
